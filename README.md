# 🤖 Telegram Anti-Delete & Edit Bot на базе Aiogram 3

Бот для сохранения удалённых и отредактированных сообщений, написанный на **aiogram 3** с использованием официального протокола **Telegram Business** (Bot API 7.2+).

---

## 📌 Как это работает в Telegram Bot API (aiogram)

В стандартном Telegram Bot API боты **не имеют доступа** к личным сообщениям пользователей и не получают уведомлений об удалении сообщений в группах.

Единственный официальный способ получать события об удалении сообщений через Bot API — это механизм **Telegram Business**:
1. Вы создаёте своего бота через **@BotFather** и получаете токен.
2. В приложении Telegram (требуется Telegram Premium) подключаете этого бота в разделе:  
   **Настройки -> Telegram для бизнеса -> Чат-боты**.
3. Теперь Telegram пересылает боту события ваших личных диалогов:
   - `business_message` — бот кэширует входящие сообщения и медиафайлы в SQLite.
   - `deleted_business_messages` — при удалении сообщения собеседником бот моментально присылает вам исходный текст и сохранённые файлы в диалог с ботом.
   - `edited_business_message` — при изменении сообщения бот присылает исходную и новую версию.

## ✨ Возможности

- 🗑 **Перехват удалённых сообщений:** сохраняет текст, имя автора, username, ID, время отправки и удаления.
- 🔥 **Перехват исчезающих фото по ответу:** если вам прислали исчезающее фото (1x или с таймером), просто ответьте на него в диалоге (например, точкой или словом), не открывая само фото — бот моментально перехватит оригинал и пришлёт его вам в диалог с ботом!
- 📎 **Сохранение медиафайлов:** фото, голосовые сообщения, видеосообщения (кружочки), видео, аудио и документы скачиваются локально в `media/` и отправляются вам при удалении.
- ✏️ **Лог редактирования:** показывает, что было в сообщении и на что его изменили.
- 📊 **Команда `/status`:** отображает статистику базы данных и статус подключений.
- 🧹 **Автоочистка:** старые сообщения и кэш автоматически удаляются через 7 дней (настраивается в `.env`).

## 🚀 Быстрый старт

### 1. Создайте бота в @BotFather
1. Откройте в Telegram **[@BotFather](https://t.me/BotFather)**.
2. Отправьте команду `/newbot`.
3. Введите название и username для вашего бота (например, `MyLoggerBot`).
4. Скопируйте полученный **токен** (вида `123456789:ABCDefGhI...`).

### 2. Настройте файл [`.env`](file:///Users/olesia/Documents/bot/.env)
Откройте файл [`.env`](file:///Users/olesia/Documents/bot/.env) и вставьте ваш токен:
```env
BOT_TOKEN=123456789:ABCDefGhI...
```

### 3. Запустите бота
```bash
cd ~/Documents/bot
./run.sh
```

### 4. Подключите бота к аккаунту
1. Откройте диалог с вашим ботом в Telegram и нажмите **Запустить** (`/start`).
2. В Telegram перейдите в **Настройки** -> **Telegram для бизнеса** -> **Чат-боты**.
3. Добавьте вашего бота (по его `@username`).
4. Настройте чаты (выберите «Все личные чаты»).
5. Бот пришлёт подтверждение: `🎉 Бизнес-подключение успешно активировано!`.

## ⚙️ Настройки ([`.env`](file:///Users/olesia/Documents/bot/.env))

| Параметр | По умолчанию | Описание |
| :--- | :--- | :--- |
| `BOT_TOKEN` | — | Токен бота от @BotFather |
| `SAVE_MEDIA` | `true` | Сохранять ли вложения (фото, аудио, голосовые, файлы) |
| `MAX_MEDIA_SIZE_MB` | `20` | Макс. размер медиа в МБ для локального кэширования |
| `LOG_EDITED` | `true` | Уведомлять об отредактированных сообщениях |
| `RETENTION_DAYS` | `7` | Срок хранения сообщений в базе до автоочистки (в днях) |

## 🖥 Фоновый запуск на Mac

Чтобы бот работал постоянно в фоновом режиме:

```bash
cd ~/Documents/bot
nohup ./venv/bin/python3 main.py > bot.log 2>&1 &
```

- **Проверить работу:** `ps aux | grep main.py`
- **Посмотреть логи:** `tail -f bot.log`
- **Остановить бота:** `pkill -f "python3 main.py"`
